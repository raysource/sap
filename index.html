SAP RAP × CAP 培训中心

一套完整、可跟做的 SAP 现代化应用开发培训：从 ABAP RESTful 应用编程模型（RAP） 到 Cloud Application Programming Model（CAP）。每个章节配有高仿真界面示意图、逐步操作手顺与可直接使用的测试数据。

S/4HANA on-premise SAP BTP Cloud Foundry ADT / Eclipse Node.js Java + Spring Boot HANA Cloud BAS Fiori Elements Integration Suite / iFlow
📌 适用读者 有基本 ABAP 语法基础、想转型现代 ABAP（RAP）开发的开发者；或想从零掌握 CAP（Node.js / Java）全栈开发的开发者。CAP 除 Node.js 路线外，还提供一条完整的 CAP for Java 路线（JDK 17 + Maven + Spring Boot），从手写 DTO 一路到生成模型、配置数据库与 OData 服务；另有 BTP 云上手顺（B1–B8：注册 → HANA Cloud 建库 → BAS 三种 Java 模式连库）。零基础也可从「环境准备」章节开始跟做。想学系统集成的开发者，可跟Integration Suite 路线（I1–I6：浏览器里画 iFlow 做消息转换与路由）。

四条技术路线

同一套业务场景（旅行社 / 书店），用 RAP 与 CAP 各实现一遍，对比两种模型的最佳实践；UI 层与系统集成另有专线。

🅰️

RAP — ABAP RESTful 应用编程模型

在 S/4HANA on-premise 上，用 CDS 视图 + Behavior + OData 服务构建 Fiori 应用。4 个手顺：数据模型 → 行为定义 → 服务定义/绑定 → Fiori 预览测试。场景：旅行社 Travel 业务对象。

CAP — Cloud Application Programming Model

在 SAP BTP / 本地 用 Node.js 或 Java + CDS 快速构建云原生 OData 服务。Node.js 路线 4 个手顺：项目初始化 → 数据模型 → 业务逻辑 → 启动测试 + Fiori；另附一条完整 Java 路线（J1–J6：环境 → 项目 → 数据库 → DTO/模型 → 测试）与一条云上手顺（B1–B8：注册 BTP → 建 HANA Cloud 库 → BAS 用三种 Java 模式连库）。场景：书店 Bookshop 业务对象。

Fiori — Fiori Elements UI 层

RAP 与 CAP 共同的门面：不写 UI5 代码，用 @UI 注解驱动生成企业级页面。3 个手顺：List Report → Object Page → Action 与双线集成；另附控件讲解（Smart Controls / sap.m 速查）与页面模板详解（Worklist / Overview / ALP / Form Entry / Custom Page）。场景：复用书店 Bookshop 的 OData 服务。

Integration Suite — 系统集成（iFlow）

把前几条路线的成果连起来：在 BTP 的 Cloud Integration（CPI）里用浏览器画 iFlow，做跨系统消息传递、转换与路由。3 个手顺：第一个 iFlow → 消息转换（Content Modifier / Groovy / Mapping）→ 内容路由（CBR）；在回显服务的镜子里验证每一步。场景：书店订单的同步、换算与加急分流。

RAP vs CAP 一图看懂

两者都基于 CDS 与 OData，但运行环境、语言与部署完全不同。选择取决于你的代码运行在哪里：S/4HANA 内 vs 云上。

维度 RAP（ABAP RESTful） CAP（Cloud Application Programming）
运行环境S/4HANA / BTP ABAP 环境（Steampunk）Node.js / Java 运行时，可部署 BTP Cloud Foundry、Kyma
编程语言ABAP（CDS DDL / BDEF / 行为实现类）JavaScript / TypeScript（或 Java）+ CDS
数据模型CDS 视图（DDL Source）CDS 模型（db/schema.cds）
业务逻辑承载Behavior Definition（BDEF）+ 实现类Service Handler（srv/*.js）或 Java 注解
服务暴露Service Definition + Service Binding → OData V2/V4service 块自动暴露 OData V4
UIFiori Elements / Freestyle（从 Binding 一键预览）Fiori Elements / Freestyle（@sap/cds-fiori）
本地开发ADT（Eclipse 插件），需连接系统VS Code + cds watch，纯本地，SQLite
数据库S/4HANA 底层数据库（HANA）开发时 SQLite，生产 HANA Cloud / 其它
适合团队现有 ABAP/S/4HANA 团队前后端/全栈 / 云原生团队

📱 Fiori 路径 UI 层 · RAP × CAP 共用

🔗 Integration Suite 路径 系统集成 · BTP Cloud Integration

前几条路线造系统，这条路线连系统：在浏览器里画 iFlow，把消息从一个系统送到另一个系统——转换、路由、监控一次走通。无需本地安装，用回显服务当「镜子」验证每一步。

  1. Integration Suite 概述iFlow 解剖 + 与 RAP/CAP 分工
  2. 环境准备BTP 开通 + 角色
  3. 手顺1：第一个 iFlowHTTP → 改写 → HTTP
  4. 手顺2：消息转换Content Modifier / Groovy / Mapping
  5. 手顺3：内容路由属性 + CBR 分流
