7.4 数据插入方式

方式一：SE16N 手工维护

登录 SAP GUI，事务码 SE16N（数据浏览器/表维护）输入表名 ZTRAVEL 后回车，可直接增删改行数据：

方式二：ABAP 程序批量插入

在 ADT 新建一个 ABAP Program（New → Other… → ABAP Program，名称 ZR_INSERT_TESTDATA），粘贴并运行即可一次性写入全部数据：

REPORT zr_insert_testdata.

DATA: lt_travel  TYPE TABLE OF ztravel,
      lt_booking TYPE TABLE OF ztravel_booking.

7.5 测试场景清单

#场景操作预期结果
1创建旅行Fiori「创建」或 POST /Travel新行状态 N 新，可编辑
2保存后编辑打开对象页 → 编辑 → 保存走 Draft，保存后写入正式表；不保存则正式数据不变
3批准选中 → 批准状态变 A 已批准，批准按钮置灰
4拒绝选中 → 拒绝状态变 X 已拒绝，拒绝按钮置灰
5删除已批准记录选中 A 记录 → 删除报错或被拒（视行为实现；本培训未限制时允许删除）
6校验无效客户创建时填不存在的 CustomerID保存报错（validateCustomer 触发）
7OData 查询GET /Travel?$filter=Status eq 'A'&$top=5&$orderby=TotalPrice desc返回正确 JSON，筛选/排序/分页生效

7.6 状态域说明

状态码名称含义徽章
NNew新蓝
OOpen处理中琥珀
AApproved已批准绿
XRejected已拒绝红
💡 使用提示
  • 批量程序用 INSERT 直插物理表，绕过行为/校验，适合造数据；若要走完整 RAP 校验，请用 Fiori 或 OData POST。
  • CREATEDAT / LASTCHANGEDAT 为 UTC 时间戳（YYYYMMDDHHMMSS），插入时保持 DEMO 值即可。
  • 手顺4 的 Fiori 列表页数据与此处一一对应，可直接对照验证。
