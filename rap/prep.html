第 2 章：环境准备

Eclipse + ADT · 连接到 S/4HANA · 创建开发包

RAP 的全部开发都发生在 ADT（ABAP Development Tools for Eclipse） 里。本章带你从零装好工具链、连上开发系统、建好后续所有章节共用的开发包 ZRAP_TRAINING。

Eclipse 2023-06 ADT 插件 ABAP Project S/4HANA 2021+ VPN / SAP Router

2.1 前置条件

开始之前，确认你拥有以下三项。缺任何一项都会卡在登录或激活环节：

🖥️ S/4HANA 系统

版本 S/4HANA 2020+（推荐 2021+）。RAP 的 strict ( 2 )、with draft 等能力在 2020 及以上才完整可用。

👤 开发账号

具备 开发权限（可创建/激活 ABAP 对象）与 后台作业 权限（Draft 与 Service 激活需要）。

🌐 网络可达

本机到系统的 22 端口 必须连通。通常通过 SAP Router（saprouter://…）或 VPN 接入。

前置项推荐值说明
系统版本S/4HANA 2021 及以上2020 亦可，但 strict ( 2 ) / 组合行为需注意版本差异
开发账号DEVELOPER 角色组至少含 S_DEVELOP、S_PROGRAM 等授权对象
网络端口22 / HTTPS 443ADT 走 RFC + HTTPS；远程系统经 SAP Router 或 VPN 接入
OData 激活SICF 节点 /sap/opu/odata4S/4HANA 通常默认激活；本培训开发系统一般已配置好

2.2 下载并安装 Eclipse

ADT 是一个 Eclipse 插件，因此先装一个官方支持的 Eclipse 版本。SAP 对每个版本有明确的兼容矩阵，本培训使用 Eclipse 2023-06（4.28），与之配套的 ADT 也来自 2023-06 的 Update Site。

  • 官网下载 Eclipse IDE for Enterprise Java and Web Developers；只做 ABAP 开发也可选更轻的 Eclipse IDE for Java Developers。
  • 解压即用，无需安装程序。首次启动会提示选择 workspace，任意目录即可（推荐单独的 D:\workspace\rap 或 ~/workspace/rap）。
  • 若内存吃紧，编辑 eclipse.ini，在 -vmargs 后加 -Xmx4096m，避免大项目卡顿。
# eclipse.ini 关键行示例
-vmargs
-Xmx4096m
-Xms512m
-Dfile.encoding=UTF-8

2.3 安装 ADT 插件

在 Eclipse 菜单 Help → Install New Software…，在 Work with 输入框粘贴 ADT 的 Update Site 地址，回车让 Eclipse 抓取插件列表：

https://tools.hana.ondemand.com/2023-06

勾选 ABAP Development Tools（必要时展开勾选 ABAP Development Tools for SAP NetWeaver 下的所有子项），点 Next 并按向导完成安装，最后重启 Eclipse。

⚠️ 版本匹配 ADT 的 Update Site 版本必须与 Eclipse 基础版本一致：Eclipse 2023-06 对应 /2023-06；装错组合会提示「No repository found」或插件冲突。ADT 的版本还需与后端 SAP 系统版本匹配——SAP GUI 端不需要，但 ABAP 后端 /IWFND 等组件版本过低时，Service Binding 会激活失败。

2.4 新建 ABAP Project（连接系统）

在 Project Explorer 空白处右键 New → Other…，搜索 ABAP Project，进入新建向导。第一步 Connection Settings 填写系统连接信息（下图），第二步 Logon / Security 选择登录方式（用户名密码或 X.509 证书）。

填写完成后点 Next，在 Logon / Security 页选择 UserName/Password，输入开发账号；也可选 Client Certificate 使用 X.509 证书免密登录。点 Finish 后 Eclipse 后台建连，Project Explorer 出现系统项目（连接成功前它会显示一个小图标，右键可 Check Connection）。

2.5 创建开发包 ZRAP_TRAINING

所有培训对象都放在一个包里，便于传输与查找。在刚建好的 ABAP Project 上右键 New → ABAP Package，向导第一步填写属性：

第二步 Package Description 填入描述（如「RAP Training for Travel」）并点击 Finish。若系统要求，会弹出请求（Transport Request）选择——选一个可写入的本地请求即可。

2.6 ADT 主界面布局

完成上述步骤后，你的 ADT 应呈现如下布局：左侧 Project Explorer（项目树），中间 编辑器，右侧 Outline（结构大纲），底部 状态栏 显示对象与激活状态。

2.7 操作手顺

  1. 下载并启动 Eclipse 2023-06

    到 https://www.eclipse.org/downloads/packages/ 下载 Eclipse IDE for Enterprise Java and Web Developers（版本 2023-06）。解压后启动，workspace 指向专用目录。

  2. 安装 ADT 插件

    Help → Install New Software…，粘贴下面地址并回车，勾选 ABAP Development Tools 安装：

    https://tools.hana.ondemand.com/2023-06

    重启 Eclipse 后，File → New → Other… 中应能看到 ABAP Project 与 ABAP Package 向导。

  3. 新建 ABAP Project

    在 Project Explorer 空白处 New → Other… → ABAP Project。按 2.4 节填写系统标识、主机、实例号、客户端与语言。

  4. 登录系统

    在 Logon / Security 页选择 UserName/Password，输入开发账号密码（或选证书登录）。点 Finish 等待连接完成。

  5. 创建开发包

    在项目上右键 New → ABAP Package，名称 ZRAP_TRAINING，命名空间 Z，软件组件 HOME，包类型 Development。勾选 Add to favorites 方便后续查找。

2.8 验证

✅ 验证清单 Project Explorer 中 D4H_DEV 连接图标无告警；右键项目 Check Connection 返回成功；Favorite Packages 中能看到 ZRAP_TRAINING；New → Other… 里可搜到 ABAP 相关向导。
💡 注意点
  • 代理 / 防火墙：若 Install New Software 一直转圈，检查 Eclipse 的 Window → Preferences → General → Network Connections，配置代理为 Active Provider 并填入代理服务器。
  • 内存：大项目建议 -Xmx4096m；32 位 JVM 无法分配超过 1.5G，请用 64 位 JDK。
  • ADT 与系统版本：后端 S/4HANA 版本过低时，Service Binding 的 OData V4 激活会失败，优先确认后端已到 S/4HANA 2020 且 /IWFND 组件激活。
  • OData 激活：若后面 Preview 打不开，检查事务 SICF 中 /sap/opu/odata4 节点是否为 Active（开发环境通常已激活）。

  1. ADT（ABAP Development Tools）本质上是什么？

    A. SAP GUI 的增强版
    B. Eclipse 的一组 ABAP 开发插件
    C. 独立的云 IDE
    D. VS Code 扩展

  2. 安装 ADT 前，选择 Eclipse 版本时最重要的注意点是什么？

    A. 必须是最新版
    B. 版本要与官方更新站点（如 tools.hana.ondemand.com/2023-06）的年份匹配
    C. 只能用 macOS 版
    D. 需要购买许可证

  3. 在 ADT 里新建 ABAP Project 连接 S/4HANA 开发系统，需要提供的信息不包括？

    A. 系统主机名 / 地址
    B. 实例号与端口
    C. SAP 客户端（Client）
    D. 显示器分辨率

    B. 便于以包为单位纳入传输请求、整体交付与管理
    C. 包能提升 SQL 性能
    D. 不建包对象无法保存

  5. 客户自己的开发对象名以什么字母开头是 ABAP 命名约定？

    A. Y 或 Z
    B. X
    C. A
    D. T

  6. 在 ADT 中创建 CDS 视图、BDEF 等对象时，会要求先选择什么？

    A. 传输请求（Transport Request）与开发包
    B. 数据库连接串
    C. 前端框架版本
    D. 用户头像

  7. 登录开发系统失败时，按链路排除顺序正确的排查项是？

    A. 网络可达性 → 端口/服务 → Client → 账号权限
    B. 账号权限 → 显示器 → 网络
    C. 数据库表 → 前端缓存
    D. 系统语言 → 时区
答案与解析（🟢 基础巩固（1–7））
题号答案解析
1BADT 是装在 Eclipse 里的插件集合，提供 CDS/BDEF/ABAP 的语义编辑器与项目视图。
2B插件与 Eclipse 平台有兼容矩阵，年份不匹配会导致装不上或功能异常。
3D连接参数是主机、端口（默认 8000 等）、Client、账号口令；分辨率跟连接无关。
4B开发包是对象归属与传输的边界；后续传输、复制、评估都基于包。
5A客户命名空间用 Y/Z 开头（Z 更常用），避免与 SAP 标准对象冲突；本课对象全部 Z 开头。
6A对象保存到系统通常伴随传输请求；也可先本地保存，交付时才建请求。
7A连接类问题按链路排查：先网络与端口，再 Client 与账号权限。
