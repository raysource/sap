第 F1 章：Fiori 概述

Fiori Elements · 注解驱动的企业级 UI，RAP 与 CAP 共同的「门面」

Fiori 是 SAP 的用户体验设计体系，而 Fiori Elements 是它的「免代码 UI 框架」：只要你的后端暴露一个 OData 服务（无论来自 RAP 还是 CAP），Fiori Elements 就能按服务元数据自动渲染出可搜索、可筛选、可编辑的企业级页面，几乎不用写一行 UI5 代码。

Fiori Elements @UI 注解 List Report Object Page UI5 Launchpad

F1.1 Fiori 是什么

Fiori 是 SAP 面向企业应用的设计语言：基于角色、响应式、简单直接。Fiori 应用通常通过 Fiori Launchpad（企业门户）统一入口访问，但本章关注的是开发侧的核心——Fiori Elements：一组预制的 UI5 页面模板（List Report、Object Page 等），它们读取 OData 服务的 $metadata 与 @UI 注解，自动生成完整页面。

① 元数据驱动

页面结构（列、表单、Facet）全部由服务注解声明，改注解即改 UI，无需改 JS 代码。

② 零代码起步

后端 OData 就绪后，几分钟内得到标准 List Report / Object Page，开箱支持搜索、筛选、分页、CRUD。

③ 可渐进扩展

标准功能不满足时，再写自定义列、自定义按钮（Action）或 Freestyle 扩展，而不是推翻重来。

F1.2 Fiori Elements 页面类型

模板用途典型页面
List Report主列表：搜索、筛选、批量操作、跳转详情订单列表、物料清单、Books 列表
Object Page单条对象详情：Header + Facets（表单/子表/文本）订单详情、Travel 详情
Overview Page仪表盘式总览：卡片聚合多个数据源销售总览、监控台
Analytical List Page图表 + 列表联动分析销售分析
Form Entry向导式录入 / 审批流首屏报销申请、入职流程

本培训 F2–F4 覆盖最常用的 List Report + Object Page 组合，外加 Action 按钮与 RAP / CAP 双线集成。

F1.3 注解驱动的 UI

Fiori Elements 的灵魂是 @UI 注解（以及 @Common、@Semantic 等辅助注解）。注解声明「页面上有什么」，框架负责「怎么渲染」。一段典型注解声明了列表标题、表格列与语义键：

annotate service.Books with @(
  UI : {
    HeaderInfo : { TypeName : 'Book', TypeNamePlural : 'Books', Title : { Value : 'title' } },
    LineItem : [
      { Value : 'title', Label : '书名' },
      { Value : 'price', Label : '价格' },
      { Value : 'stock', Label : '库存' }
    ]
  },
  Common.SemanticKey : ['ID']
);

注解写在哪里取决于后端：RAP 在 CDS 视图（消费视图 / 元数据扩展）里写 @UI 注解；CAP 在 app/*/annotate.cds 里用 annotate 叠加。位置不同，机制相同——都是给 OData 服务的元数据「加注释」。

F1.4 Fiori 是 RAP 与 CAP 共同的「门面」

RAP 与 CAP 各有一套后端栈，但前端殊途同归：OData V4 服务 → Fiori Elements。本培训前两条路线的第 4 个手顺都已预览过 Fiori（RAP 手顺4 的 Service Binding Preview、CAP 手顺4 的 app/ 目录），本章把这些体验系统化：

维度RAP 侧CAP 侧
注解位置CDS 视图 / 元数据扩展（@UI.*）app/*/annotate.cds 的 annotate
预览方式Service Binding → Preview（系统自带）cds watch + /app/books/index.html
生成工具ADT 新建 Fiori 元素 / 预览模板cds add fiori 或 Fiori Tools
编辑模式Draft（草稿）机制直接编辑 + @Common 注解可配 Draft

F1.5 环境准备（复用 CAP 环境）

本 Fiori 章节的实操全部基于 CAP Bookshop 工程（素材包 samples/cap-bookshop），因此环境与 CAP 路线一致：

  • Node.js 18+ 与 cds-dk：见 CAP 环境准备；samples/cap-bookshop 已含 package.json，npm install && cds watch 即可。
  • VS Code：改 annotate.cds 与 manifest.json 用；可选安装 Fiori Tools（@sap/ux-ui5-tooling 扩展包，用于 F2 的脚手架生成）。
  • 浏览器：直接访问 http://localhost:4004/app/books/index.html 预览。
