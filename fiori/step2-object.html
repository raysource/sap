第 F3 章：手顺2 —— Object Page 与 Facets

点列表行进详情页 · Header + @UI.Facet 组织表单与子表

Fiori Elements 的「List Report + Object Page」是天生一对：在 List Report 里点任意一行，自动进入该条数据的 Object Page 详情页。详情页长什么样，完全由 @UI.Facet 注解决定——本章把 Books 的详情页拆成「基本信息」表单与「订单」子表两个区块。

Object Page @UI.Facet FieldGroup Header 关联子表

F3.1 Facet 是什么

Facet（页签/区块）是 Object Page 的内容组织单元。每个 Facet 是一块区域，可以是表单（FieldGroup）、子表（LineItem）、图表或纯文本。UI.Facet 数组决定这些区块的顺序与嵌套，三个最常用的子类型：

Facet 类型渲染效果典型用途
UI.Identification对象页顶部 Header 的附加字段关键业务字段常驻头部
UI.FieldGroup表单区块（字段+标签网格）基本信息、地址、备注
UI.LineItem（在 Facet 内）内嵌子表子实体列表：订单、明细行、预订

F3.2 annotate.cds：声明详情页布局

继续在 app/books/annotate.cds 上扩展。给 Books 追加 UI.Facet 与字段分组，同时为子表准备好 Orders 的投影——子表数据来自 Orders 实体（Bookshop 模型里 Orders.book 指向 Books）：

// app/books/annotate.cds —— 追加对象页布局
using CatalogService as service from '../../srv/cat-service';

annotate service.Books with @(
  UI : {
    HeaderInfo : {
      TypeName : 'Book', TypeNamePlural : 'Books',
      Title : { Value : 'title' },
      Description : { Value : 'author.name' }
    },
    // —— 对象页 Facet 布局：基本信息 + 订单子表 + 补充信息 ——
    Facets : [
      { $Type : 'UI.ReferenceFacet', Target : '@UI.FieldGroup#general',    Label : '基本信息' },
      { $Type : 'UI.ReferenceFacet', Target : '@UI.LineItem#orders',       Label : '订单' },
      { $Type : 'UI.ReferenceFacet', Target : '@UI.FieldGroup#more',       Label : '补充信息' }
    ],
    FieldGroup #general : {
      Data : [
        { Value : 'title', Label : '书名' },
        { Value : 'author.name', Label : '作者' },
        { Value : 'genre.name', Label : '分类' },
        { Value : 'descr', Label : '描述' }
      ]
    },
    FieldGroup #more : {
      Data : [
        { Value : 'price', Label : '价格' },
        { Value : 'currency', Label : '币种' },
        { Value : 'stock', Label : '库存' }
      ]
    },
    LineItem #orders : [
      { Value : 'ID', Label : '订单号' },
      { Value : 'quantity', Label : '数量' },
      { Value : 'createdAt', Label : '下单时间' }
    ],
    HeaderInfo : { TypeName : 'Book', TypeNamePlural : 'Books' }
  },
  Common.SemanticKey : ['ID']
);

// —— Orders 投影：子表数据源（含 createdAt）——
annotate service.Orders with @(
  UI.LineItem : [
    { Value : 'ID', Label : '订单号' },
    { Value : 'quantity', Label : '数量' },
    { Value : 'createdAt', Label : '下单时间' }
  ]
);
  • UI.Facets：对象页主内容区的区块列表，按声明顺序从上到下排列；Target 用 @UI.xxx#key 引用下方命名的注解块。
  • FieldGroup #general：带 # 后缀的「命名注解块」，Data 数组声明表单字段与标签。
  • LineItem #orders：内嵌子表列定义；对象页里子表自动显示在对应 Facet 区块。
  • 子实体也要注解：子表实际渲染的是 Orders 实体的列表，所以对 service.Orders 同样给出 UI.LineItem。
⚠️ 子表需要关联与权限 Fiori Elements 渲染子表要求实体间存在可导航关联（Orders.book → Books）且服务已暴露 Orders。素材包的 cat-service.cds 已暴露 Orders；若你的服务没暴露，先回到 CAP 手顺2 把 Orders 加进服务定义。

F3.4 操作手顺

  1. 扩展注解

    在 app/books/annotate.cds 追加 UI.Facets + 两个 FieldGroup + LineItem #orders，并对 service.Orders 补充 UI.LineItem（见F3.2）。

  2. 确认服务暴露 Orders

    检查 srv/cat-service.cds 中 Orders 已在服务内（素材包已含）；缺失则补上并重启 cds watch。

  3. 预览与点击导航

    刷新 http://localhost:4004/app/books/index.html，点击任意一行进入对象页，核对三个 Facet 区块与图 F3-1一致。
