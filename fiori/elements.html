第 F5 章：主要元素控件讲解

Smart Controls 与 UI5 基础控件 · 「注解 → 控件」的装配对照

Fiori Elements 页面上的每个部件都对应一个控件：筛选栏、表格、表单、按钮、徽标……本章把「注解写到哪 → 页面上长出什么控件」的对应关系讲透，再速查一组最常用的 sap.m 基础控件（做 Freestyle 扩展时手写它们）。

Smart Controls sap.m Smart Filter Bar Smart Table Smart Form Freestyle 扩展

F5.1 两个层次：Smart Controls 与 UI5 基础控件

Fiori 前端控件分两层，职责完全不同：

① Smart Controls（智能控件）

Fiori Elements 的装配件：读取 OData 元数据与 @UI 注解自动生成内容。你声明「有什么」，它决定「长什么样」。例如 Smart Filter Bar 根据 SelectionFields 自动生成筛选项，改注解即改 UI。

② UI5 基础控件（sap.m / sap.ui.table…）

UI5 框架的原子积木：Input、Table、Button 这类单个控件。Smart Controls 内部也是由它们拼装的；你在 Freestyle 页面 / 自定义扩展里手写的就是这一层。

💡 一句话区分 用 Fiori Elements 默认模板 → 你碰 Smart Controls（写注解）；写自定义页面、自定义列、自定义 View 扩展 → 你碰 UI5 基础控件（写 XML/JS）。Smart Controls 是「别人按注解帮你拼好的 UI5 基础控件」。

控件作用出现的页面对应注解

F5.5 什么时候手写控件：一个 Freestyle 小例子

当注解表达不了需求（比如做一个特殊的统计卡片），就新建自定义页面，手写 UI5 控件。一个最小例子——用 sap.m 控件拼一张「库存速览」页（XML 视图 + 控制器里取数）：

<!-- app/inventory/inventory.view.xml —— 手写 UI5 控件 -->
<mvc:View xmlns:mvc="sap.ui.core.mvc" xmlns="sap.m"
          controllerName="cap.bookshop.inventory">
  <Page title="库存速览">
    <Toolbar>
      <Input id="book" placeholder="输入书 ID" width="180px"/>
      <Button text="查询" press="onQuery"/>
    </Toolbar>
    <List id="list" items="{/Books}">
      <ObjectListItem
          title="{title}"
          number="{stock}"
          numberUnit="件"
          status="{= ${stock} > 0 ? 'In Stock' : 'Sold Out'}"/>
    </List>
    <MessageStrip id="msg" visible="false" type="Error" text="库存不足"/>
  </Page>
</mvc:View>
  • Page：页面骨架（页头 + 内容 + 页脚）。
  • Toolbar + Input + Button：查询条件区；按钮事件绑到控制器 onQuery。
  • List + ObjectListItem：数据绑定到 /Books（OData 集合），字段用 {title} 花括号表达式绑定。
  • MessageStrip：业务校验失败时的内嵌错误提示。
  • 表达式绑定：= ${stock} > 0 ? … 这种行内逻辑无需写控制器代码。
📌 学习路径建议 先掌握 F1–F4 的「注解优先」，把 Smart Controls 用熟；需要自由排版、复杂交互或图表时再引入 Freestyle 手写控件。Smart Controls 能覆盖 80% 的标准企业页面。

F5.6 动手观察：在预览页里找控件

  1. 打开 F2 的 List Report 预览

    cds watch 后访问 http://localhost:4004/app/books/index.html。

  2. 按对照表逐区认领

    用 F5.2 的编号在页面上找：筛选栏（Smart Filter Bar）、表格（Smart Table）、标题（HeaderInfo）、分页条。

  3. 改注解看变化

    给 LineItem 增删一列，或给 SelectionFields 增删一个筛选字段，刷新页面——观察对应控件区域随之变化，这就是「注解驱动」。

  4. F12 看控件树

    浏览器按 F12 → Elements / 调试器，搜索 smartfilterbar、smarttable 等 DOM 节点，亲眼确认控件真实身份。
