第 F2 章：手顺1 —— List Report

cds add fiori 脚手架生成 → annotate.cds 定制列与筛选 → 浏览器预览

在 CAP 手顺4 里我们手写过 annotate.cds + manifest.json；本章用脚手架（cds add fiori）自动生成同样的一堆文件，再通过注解把列表定制成想要的业务页面。前置条件：Bookshop 工程能 cds watch 启动（用 素材包 即可）。

cds add fiori annotate.cds List Report manifest.json Fiori Tools

F2.1 步骤1：脚手架生成 List Report

在工程根目录执行 cds add fiori（由 @sap/cds-fiori 插件提供；旧版需先 npm i -D @sap/cds-fiori）。命令是交互式的，按提示选择：

?  Which template? List Report Object Page

图 F2-1 cds add fiori 交互选择服务 / 实体 / 模板，自动生成 app/books/ 三件套

生成后工程多出 app/books/ 目录，与手写方式的结构完全一致——脚手架只是把 CAP 手顺4 6.3 的「三件套」代劳了：

bookshop — 生成后新增
▾📁 app/
▾📁 books/ ← Fiori Elements List Report
📄 annotate.cds ← @UI 注解（改 UI 就改这里）
📄 manifest.json ← 应用配置 / 数据源
📄 index.html ← 引导页

F2.2 步骤2：用 annotate.cds 定制列表

打开 app/books/annotate.cds，把默认占位注解换成业务定制的：列表标题、可筛选字段（SelectionFields）与表格列（LineItem）：

// app/books/annotate.cds —— 定制 Books 列表
using CatalogService as service from '../../srv/cat-service';

annotate service.Books with @(
  UI : {
    HeaderInfo : {
      TypeName : 'Book', TypeNamePlural : 'Books',
      Title : { Value : 'title' },
      Description : { Value : 'author.name' }
    },
    SelectionFields : ['title', 'author.name', 'price'],   // ← 筛选栏出现 3 个筛选项
    LineItem : [
      { Value : 'title', Label : '书名' },
      { Value : 'author.name', Label : '作者' },
      { Value : 'genre.name', Label : '分类' },
      { Value : 'price', Label : '价格' },
      { Value : 'stock', Label : '库存' },
      { Value : 'stock', Label : '状态', Criticality : 'criticality' } // 预留，见 F4
    ]
  },
  Common.SemanticKey : ['ID']
);
  • UI.HeaderInfo：列表页与对象页的标题区——单复数名、主标题字段、描述字段（这里直接显示作者姓名，author.name 是关联路径）。
  • UI.SelectionFields：声明筛选栏出现哪些字段，用户可组合过滤；不声明则无筛选栏。
  • UI.LineItem：表格列定义；Value 支持关联路径（genre.name）把外键列渲染成可读名称。
  • 相对路径：annotate.cds 在 app/books/ 下时，using ... from 指向 ../../srv/cat-service（回到CAP 手顺4 复习路径规则）。
💡 脚手架 vs 手写 cds add fiori 只是生成初始文件，之后定制仍靠手写注解。两种方式产出的文件与效果完全等价——脚手架适合起步，手写适合已存在的工程。企业级开发常用 VS Code 的 Fiori Tools（Application Generator）以向导方式完成同样的事，原理一致。想直接拿最终成果：Fiori 素材包（samples/fiori-bookshop）提供了做完 F2–F4 后的 app/books/ 三件套，复制进 Bookshop 工程即得完整页面。

F2.4 操作手顺

  1. 启动工程

    复制 素材包 samples/cap-bookshop，npm install 后 cds watch，确认 http://localhost:4004/odata/v4/catalog 可访问。

  2. 生成脚手架

    执行 cds add fiori，依次选择 CatalogService → Books → List Report Object Page（见图 F2-1）。

  3. 定制注解

    按 F2.2 改写 app/books/annotate.cds：HeaderInfo、SelectionFields、LineItem。

  4. 预览验证

    刷新 http://localhost:4004/app/books/index.html，确认筛选栏 3 个筛选项、5 列表格与图 F2-3一致。
