第 F6 章：页面模板详解

List Report · Worklist · Object Page · Overview Page · ALP · Form Entry · Custom Page

Fiori Elements 提供一组预制页面模板，每个模板对应一类典型业务场景。前几章已亲手做过 List Report 与 Object Page；本章把全套模板逐个讲透——长什么样、管什么用、用什么注解驱动，并给出「选哪个模板」的决策思路。

List Report Worklist Object Page Overview Page ALP Form Entry Custom Page

F6.1 模板总览

模板页面结构典型场景驱动注解
List Report筛选栏 + 表格，点击行进详情主数据维护、订单列表（本培训 F2）SelectionFields + LineItem
Object PageHeader + Facet 区块详情页单条对象详情（本培训 F3）Facets + FieldGroup
Worklist待办任务列表，逐条「开始处理」审批、工单派发、待处理事项LineItem + 状态字段 + Action
Overview Page卡片式仪表盘：KPI + 列表 + 图表销售总览、监控台、管理驾驶舱@UI.Identification 卡片配置
Analytical List Page筛选栏 + 图表区 + 明细表格销售分析、趋势对比LineItem + 分析注解（@Analytics）
Form Entry向导式分步表单报销申请、入职流程、订单录入FieldGroup 分步
Custom Page自由布局（Freestyle）特殊交互、混合内容页面手写 UI5 控件（见 F5.5）

F6.2 List Report（F2 已实战）

「筛选 + 表格 + 跳详情」三件套，企业应用最常用。结构：顶部标题/搜索 → Smart Filter Bar（SelectionFields）→ Smart Table（LineItem）→ 点击行进入 Object Page。回到手顺1复习。

F6.3 Worklist —— 待办任务列表

Worklist 是「接下来我要处理什么」的页面：按状态/优先级列出待办，通常配一个「处理」按钮直接推进业务（审批、确认、派单）。用 Travel 审批场景示意——列表项显示客户、金额、状态徽标与处理按钮：

图 F6-1 Worklist：顶部待办计数 + 状态筛选 + 任务列表项（ObjectListItem），「处理」按钮触发审批 Action

与 List Report 的区别：List Report 面向「查询管理全部数据」，Worklist 面向「处理待办」，列表项更强调状态与操作。实现上仍是注解驱动：LineItem 定义列/字段，状态用 Criticality 着色，「处理」是服务端 Action（RAP 的 accepttravel、CAP 的 submitOrder 同款思路，见 F4）。

💡 Worklist 模板说明 Worklist 是 Fiori Elements（OData V2）的经典模板；OData V4 下通常用 List Report + 状态筛选实现同样效果。生成时在 Fiori Tools / cds add fiori 的模板列表里选 Worklist 即可。

F6.4 Object Page（F3 已实战）

详情页骨架：Header（HeaderInfo + Identification）承载关键信息与操作按钮，下方 Facet 区块（表单/子表/图表）按 UI.Facets 顺序渲染，支持页签式与锚点式导航。回到手顺2复习。

F6.6 Analytical List Page —— 分析列表

ALP = 筛选 + 图表区 + 明细表，点击图表柱/扇区联动过滤下方表格。适合「先看趋势，再钻取明细」：

F6.8 Custom Page —— 自由布局

前六个模板都是「固定骨架 + 注解填充」；Custom Page 是白纸：手写 UI5 控件自由排版（见 F5.5 的例子）。适合特殊交互、混合多数据源、品牌页。

F6.9 怎么选模板

业务问题选它
查数据、维护主数据、增删改查？List Report + Object Page（F2/F3 的经典组合）
「我有哪些待办要处理」？Worklist（状态 + 处理按钮）
老板要一屏看全局 KPI？Overview Page（多卡片多服务）
先看趋势图表、再钻取明细？Analytical List Page（需聚合查询）
长表单分步录入 / 流程首屏？Form Entry
以上都不合适？Custom Page（Freestyle）

F6.10 怎么生成

所有模板都通过同一套工具生成，只是选不同的模板名：

模板cds add fiori / Fiori Tools 模板名备注
List ReportList Report Object Page本培训 F2 已走通
Object PageObject Page可单独生成，通常随 List Report
WorklistWorklistOData V2 模板；V4 用 List Report + 状态筛选替代
Overview PageOverview Page需要 OverviewService / KPI 视图
ALPAnalytical List Page需要分析视图 + 聚合查询
Form EntryForm Entry Object按 FieldGroup 分步
Custom PageCustom Page选 Basic / Freestyle 变体
🎯 本培训怎么用 把 F2/F3 的 Bookshop 工程复制一份，分别用 cds add fiori 选 Overview Page、Form Entry Object 各生成一次，对照本章 mockup 观察默认页面——用「生成 → 看 → 注解微调」循环熟悉每个模板，比背模板列表有效得多。
