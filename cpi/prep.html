第 I2 章：环境准备

BTP 账号 → 订阅 Integration Suite → 分配角色 → 打开 Cloud Integration Web UI

本路线唯一的环境就是浏览器里的 BTP。Cloud Integration（CPI）在 BTP 上以「订阅」方式提供，开通后你会得到一个独立租户的 Web UI，之后所有章节都在里面操作。全程无需安装任何本地软件。如果你跟过 BTP 路线（B2 章），账号与子账号已就绪，可直接从 I2.2 开始。

SAP BTP Cockpit Subscription 角色集合 Cloud Integration 租户 Trial / Free Tier

I2.1 准备一个 BTP 账号（没有的话）

两种常见渠道，任选其一；本质都是「在某个 Global Account 下有一个能开通服务的子账号」：

渠道适合谁要点
BTP Trial（试用账号）个人自学注册即得 Global Account + 子账号 + Cloud Foundry；每晚休眠、无生产 SLA，适合照本课程跟做。
企业账号 + Free Tier有企业 BTP 许可的开发组在子账号里启用 Free Tier 计划即可开 Integration Suite 免费层（额度受限，教学够用）。

开通账号后，进入你的子账号（Subaccount）（Trial 默认已建好一个）。如果你对「Global Account / 子账号 / Cloud Foundry org/space」还没感觉，先看 B2 环境准备（BTP 账号） 的前半段。

I2.2 订阅 Integration Suite

在子账号里：

  1. 打开 Service Marketplace

    左侧导航 → Services → Service Marketplace，搜索 Integration Suite（也可能叫 SAP Integration Suite）。

  2. 订阅

    点开该服务 → Create / Subscribe。计划（Plan）选择你账号可用的那个——Trial 常见 Integration Suite, trial，企业 Free Tier 常见 free。计划名因账号类型而异，没有确切名字时选唯一可用项即可。

I2.3 分配角色（首次必做）

订阅完成后点 Go to Application，浏览器会跳到你的 Cloud Integration 租户（地址形如 https://<租户ID>-tmn.<区域>.hana.ondemand.com）。第一次打开往往报「无权限」，因为你的 BTP 用户还没有被授权进租户——需要把角色集合分配给自己的用户：

  1. 回到 BTP Cockpit

    子账号 → Security → Users → 点击自己的用户（通常来自你的登录邮箱 / IDP）。

  2. 加角色集合

    订阅 Integration Suite 时系统会预生成一组角色集合（列表里名字含 Integration 的那些）。把 管理员 / 开发 / 监控三件套都勾给自己的用户，常见组合：

    角色（AuthGroup 前缀）干什么用本课程需要
    Integration_Provisioner租户级管理员，首次配置、用户管理✅（I2 之后其实不用）
    AuthGroup_IntegrationAdministrator部署、取消部署、管理集成内容✅
    AuthGroup_IntegrationDeveloper在 Design 里建包、画 iFlow、写脚本✅ 核心
    AuthGroup_IntegrationOperator只读监控（MPL、消息队列）✅
    AuthGroup_IntegrationBusinessExpert查看/编辑业务场景配置—

  3. 重新登录租户

    回到 Cloud Integration 页面刷新（必要时退出重登一次，让角色生效）。

I2.4 认识 Cloud Integration Web UI

登录成功后，你会进入 Cloud Integration 主界面。记住四个入口的位置，之后每个手顺都在里面切换：

I2.5 验证与注意

  • 验证：Design 区能正常打开 Integration Packages 列表即为环境就绪（空列表没关系）。
  • 租户地址：记住你的租户域名（…-tmn.<区域>.hana.ondemand.com），I3 拼测试端点要用。
  • Trial 休眠：Trial 子账号夜间休眠，若页面打不开先回 Cockpit 重启；长期不用的 Trial 可能被回收，重要内容记得导出（iFlow 可整包 Download）。
  • 配额：试用/免费层对并发消息数、存储、运行时长短都有限制，仅供教学；本课程每个手顺只有一两次调用，不会触顶。

答案与解析（🟢 基础巩固（1–7））
题号答案解析
