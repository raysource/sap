第 2 章：环境准备

Node.js + cds-dk + VS Code —— 十分钟跑起本地 CAP 开发环境

CAP 开发只需要三样东西：Node.js（运行时）、@sap/cds-dk（命令行脚手架）、VS Code（编辑器）。数据库先用 CAP 内置的 SQLite，部署到云端时才需要 BTP 账号。

Node.js ≥ 18 @sap/cds-dk VS Code SQLite git（可选） BTP 账号（可选）

2.1 前置要求：Node.js 与 npm

CAP 的 Node.js 运行时要求 Node.js ≥ 18，官方推荐 20 LTS（长期支持版，2026 年仍在维护期内）。npm 随 Node.js 一起安装，无需单独安装。

  • 下载地址：https://nodejs.org，选择 20 LTS 安装包。
  • macOS 用户也可以用 Homebrew：brew install node@20。
  • 安装完成后，打开终端验证版本。
终端 — 验证 Node.js
$ node -v
v20.11.1
$ npm -v
10.2.4
$ which node
/usr/local/bin/node
图 2-1 安装完成后在终端验证：node -v 输出 ≥ v18（推荐 v20），npm -v 输出 npm 版本号

2.2 安装 cds-dk 脚手架

cds-dk 是 CAP 的命令行工具包，提供 cds init（建项目）、cds watch（启动开发服务器）、cds compile（编译模型）等命令。用 npm 全局安装：

npm install -g @sap/cds-dk

安装后用 cds --version 确认版本，用 cds --help 查看可用子命令。

终端 — 安装并验证 cds-dk
$ npm install -g @sap/cds-dk
npm - added 183 packages in 9s
 
$ cds --version
@sap/cds    : 8.4.1
@sap/cds-dk : 8.2.1
 
$ cds --help
Usage: cds [options] [command]
Commands: init | watch | compile | build | add | serve | run | help ...
图 2-2 cds --version 显示框架与脚手架版本，cds --help 列出全部子命令

2.4 可选：SQLite 与 git

  • SQLite：CAP 开发时默认使用 SQLite，数据库引擎与驱动由 @sap/cds 自动引入，不需要手动安装。首次启动时自动创建本地数据库文件。
  • git：建议安装用于版本管理。macOS 自带 git；Windows 可安装 Git for Windows。

2.6 操作手顺

  1. 安装 Node.js LTS

    访问 https://nodejs.org 下载 20 LTS 安装包，一路「Next」完成（macOS 亦可 brew install node@20）。

  2. 验证 Node.js 与 npm

    终端执行 node -v 与 npm -v，能输出版本号即成功（见图 2-1）。

  3. 全局安装 cds-dk

    执行 npm install -g @sap/cds-dk，随后用 cds --version 与 cds --help 验证（见图 2-2）。

  4. 安装 VS Code 与 4 个必装扩展

    安装 VS Code，在扩展市场安装 SAP CDS Language Support、SAP Fiori tools、Prettier、REST Client（见图 2-3）。

  5. 整体验证环境就绪

    在临时目录执行 cds init smoke 生成项目，再 cd smoke && cds watch，看到 server listening on http://localhost:4004 即环境就绪（第 3 章详解每条命令）。

⚠️ 网络与版本注意事项
  • npm 镜像：国内网络安装慢时，配置镜像源：npm config set registry https://registry.npmmirror.com。
  • 全局安装权限不足：报 EACCES 时用 sudo npm install -g @sap/cds-dk，或按 npm 官方文档把全局目录改到用户目录（无需 sudo）。
  • 版本兼容：cds-dk 8.x 要求 Node.js ≥ 18；Node 22 亦可运行，但生产环境推荐 20 LTS。
