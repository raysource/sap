第 3 章：手顺1 —— 项目初始化

cds init bookshop：一行命令生成可运行的项目骨架

环境就绪后，我们用 cds init 生成书店 Bookshop 项目骨架，安装依赖，最后用 cds watch 验证服务器能启动。本章只搭骨架，业务内容从第 4 章开始填写。

cds init Node.js package.json cds watch

3.1 cds init 生成项目

cds init 是 cds-dk 提供的项目脚手架命令，默认生成一个 Node.js 运行时的最小骨架。常用参数：

参数说明
cds init bookshop在当前目录下创建 bookshop/ 项目（默认 Node.js 运行时）
--mta同时生成 MTA（Multitarget Application）部署描述文件，供后续部署到 Cloud Foundry 使用
--java改用 Java 运行时（本项目用 Node.js，不使用）
--force目录已存在时强制覆盖
终端 — cds init bookshop
$ cds init bookshop

生成的 bookshop/ 目录遵循 CAP 的「三目录」约定（对照第 1 章）：

图 3-2 初始骨架只有三个顶层目录 app / db / srv 加上配置文件

逐目录职责：

📁 app/

前端应用目录。存放 Fiori Elements / UI5 应用（如第 6 章的 List Report）。初始为空。

📁 db/

数据层。核心文件 schema.cds 声明实体；db/data/ 放 CSV 种子数据。

📁 srv/

服务层。srv/*.cds 声明 OData 服务，srv/*.js 写业务逻辑。

3.5 认识 package.json 与 .cdsrc.json

package.json 声明了项目的依赖与脚本（cds init 生成的默认内容）：

{
  "name": "bookshop",
  "version": "1.0.0",
  "description": "A simple bookshop for demonstration purposes",
  "dependencies": {
    "@sap/cds": "^8"
  },
  "scripts": {
    "start": "cds serve",
    "watch": "cds watch"
  }
}
  • "dependencies"：核心依赖 @sap/cds（CAP 运行时）。后续第 4 章加模型、第 6 章加 Fiori 时，可能需要追加依赖。
  • "scripts"：npm start 等价 cds serve（生产启动）；npm run watch 等价 cds watch（开发热重载）。

.cdsrc.json 是 CAP 的配置文件，可以放部署（mta）、数据库、日志等全局配置。初始内容很简略：

{
  "mta": {
    "name": "bookshop"
  },
  "db": {
    "database": "sqlite"
  }
}

"db": { "database": "sqlite" } 明确本地开发使用 SQLite，生产部署时替换为 HANA Cloud。

3.6 首次启动验证

骨架搭好了，先跑一次 cds watch 确认服务器能启动（OData 接口与业务内容的测试放到第 6 章深入）。cds watch 会实时监听文件变化，改动保存后自动重载：

终端 — cds watch
$ cds watch
[cds] - watching for changes ...
[cds] - serving empty service { path: '/' }
[cds] - server listening on http://localhost:4004
[cds] - [ terminate with ^C ]
图 3-5 cds watch 启动开发服务器，监听 http://localhost:4004；此时还没有任何服务，第 4 章添加模型后此处会列出服务路径

3.7 操作手顺

  1. 生成项目骨架

    在想要放项目的目录执行 cds init bookshop（需要 MTA 部署文件可加 --mta），确认输出见图 3-1。

  2. 查看项目结构

    对照图 3-2逐目录检查 app/、db/、srv/ 与配置文件是否齐全。

  3. 安装依赖

    执行 cd bookshop && npm install，等待出现 added 121 packages ... found 0 vulnerabilities（见图 3-3）。

  4. 用 VS Code 打开项目

    执行 code bookshop，确认资源管理器能看到项目文件（见图 3-4）。

  5. 启动验证

    执行 cds watch，看到 server listening on http://localhost:4004 即骨架可运行（见图 3-5）。按 Ctrl+C 停止。

⚠️ 首次安装与端口注意事项
  • 首次 npm install 较慢：需要下载上百个包，耐心等待；若卡住可先配置镜像源（见第 2 章）。
  • 端口 4004 被占用：报 EADDRINUSE 时换个端口：cds watch --port 4005。
  • 包版本：@sap/cds: ^8 会解析为当前最新的 8.x，功能与本教材一致。
