第 B1 章：BTP 与 HANA Cloud 概述

从「本地 CAP」到「云端动手」——认识 BTP 平台、HANA Cloud 数据库与 BAS 开发环境

前面的 CAP 主路线与 Java 路线都在本地（SQLite 数据库、自己的终端）完成。本章开始把同一套 Bookshop 场景搬到SAP BTP 云平台：用 HANA Cloud 存数据、用 Business Application Studio（BAS） 写 Java 代码。你将亲手从注册账号走到三种 Java 构建模式连上云端数据库，完成一次完整的「本地 → 云」动手。

SAP BTP HANA Cloud Business Application Studio Cloud Foundry JDBC / ngdbc

B1.1 BTP 是什么

SAP Business Technology Platform（BTP） 是 SAP 的企业级 PaaS（平台即服务）云平台。开发者在这上面部署应用、接入数据库、集成系统、扩展 S/4HANA。本课程用到它的三样东西：

BTP 能力本课程的用途出现章节
Cloud Foundry 运行时承载应用运行环境（org / space 两级空间）B2
HANA Cloud云端内存数据库——我们建 Bookshop 库、灌数据、被 Java 连B3 / B4
Business Application Studio（BAS）云端开发环境——浏览器里的 VS Code 风格 IDE + 终端B5–B8
📌 本轨与前面路线的衔接 前面的 CAP 路线在本地用 SQLite + cds watch；本轨用 HANA Cloud + JDBC 直接连库。两者共用同一份 Bookshop 数据模型与 10 本书种子数据——数据库换了，数据长一样。

B1.3 三种环境一表对比

本轨帮你打通「本地开发 → 云端数据库」的链路。先看清三种环境各自扮演的角色：

维度 RAP（S/4HANA on-premise） CAP 本地开发 本轨（BTP + HANA Cloud）
运行位置企业自己的 S/4HANA 系统你自己的电脑SAP 云（BTP）

B1.4 本轨学习路径

共 8 章（B1–B8），前 4 章把云端数据库搭起来，后 4 章用三种 Java 构建模式连上它。建议顺序跟做：

  1. 环境准备（BTP 账号）注册 → Cockpit → 子账号
  2. 手顺1：创建 HANA Cloud 实例创建 → 等 RUNNING → 记连接信息
  3. 手顺2：HANA SQL 建表与数据schema + 3 表 + 10 本书
  4. 手顺3：BAS 入门Dev Space + 终端 + 驱动
  5. 手顺4：模式一 目录式纯 javac / java
  6. 手顺5：模式二 Mavenarchetype + exec
  7. 手顺6：模式三 Spring BootREST + curl
🎯 终点长什么样 B8 完成后，你会在 BAS 里跑起一个 Spring Boot 应用，curl http://localhost:8080/api/books 会返回 HANA Cloud 里那 10 本书的 JSON——一条「注册 → 建库 → 写 Java → 连库 → 出数据」的完整云链路。
