第 B5 章：手顺3 BAS 入门

创建 Dev Space（Full Stack Cloud Application）→ 打开工作区 → 认识终端 → 准备 ngdbc 驱动

Business Application Studio（BAS） 是 SAP 的云端开发环境——一个跑在浏览器里的「VS Code」：有文件树、编辑器、内置终端，还预装了 Java / Maven / Cloud Foundry CLI / Database Explorer 扩展。B6–B8 的三个 Java 程序都在这里写、这里编译、这里运行。

B5.3 三种 Java 构建模式对比

从 B6 开始，我们要用三种方式写同一个「连 HANA 读 Books」的小程序。先看清差别，选择最适合你的：

模式构建工具章节适合特点
模式一 · 目录式无（javac / java 裸编译）B6零工具依赖，看 JDBC 本质两个 .java + 一个 jar，命令最简单
模式二 · MavenMaven（archetype + exec 插件）B7标准 Java 工程、依赖管理pom.xml 声明依赖，mvn compile exec:java
模式三 · Spring BootMaven + Spring BootB8真实 Web 服务开发JdbcTemplate + REST，curl 出 JSON
💡 三个模式共同点 都连同一个 jdbc:sap://<主机>:443?encrypt=true&validateCertificate=true，都用 DBADMIN 用户，跑的都是 同一段联表 SELECT（B4.5 那一段）。区别只在「怎么编译、怎么把程序组织起来」。

B5.4 准备 ngdbc 驱动

Java 连 HANA 需要 SAP 的官方 JDBC 驱动 ngdbc（com.sap.cloud.db.jdbc:ngdbc，驱动类 com.sap.db.jdbc.Driver）。模式一要手动下载 jar 放到 lib/；模式二/三在 pom.xml 里声明依赖，Maven 自动下载。手动下载方式：

# 在 BAS 终端里创建 lib 目录并下载 ngdbc（版本以 Maven Central 为准）
mkdir -p bookshop-dir/lib
curl -L -o bookshop-dir/lib/ngdbc.jar \
  https://repo1.maven.org/maven2/com/sap/cloud/db/jdbc/ngdbc/2.28.8/ngdbc-2.28.8.jar

# 验证
ls -la bookshop-dir/lib/
# → -rw-r--r--  1 user  staff  2338... ngdbc.jar
🔎 ngdbc 是什么 native gDB Client 的缩写，SAP 为 HANA 提供的 JDBC 4.x 驱动，支持 HANA Cloud 的 TLS 加密连接（也就是 encrypt=true&validateCertificate=true 这套）。版本号请以 Maven Central 当前版本为准——示例里的 2.28.8 只是写稿时的版本。

B5.5 操作手顺

  1. 订阅并打开 BAS

    子账号 → Service Marketplace → Business Application Studio → Create Subscription / 打开应用，进入 BAS 首页。

  2. 创建 Dev Space

    点 Create Dev Space：名称 bookshop-dev，模板 Full Stack Cloud Application，Create（见图 B5-1）。

  3. 等 RUNNING 并打开

    列表状态到 RUNNING 后点名称，在新标签页打开工作区（见图 B5-2）。

  4. 确认终端与工具

    底部打开 TERMINAL，依次执行 java -version、mvn -version 确认 JDK 17 + Maven 就绪（见图 B5-3）。

  5. 下载 ngdbc 驱动（模式一用）

    按 B5.4 的命令下载 ngdbc.jar 到 bookshop-dir/lib/。做模式二/三的可以跳过这步。

  6. 整体验证环境

    终端里能正常敲命令、目录能创建文件即可。B6 章开始写第一个 Java 程序。

⚠️ 常见问题
  • Dev Space 启动失败：trial 的 BAS 有资源上限，若别的 Dev Space 占满，先删掉不用的再启动。
  • 找不到 Terminal：顶部菜单 Terminal → New Terminal，或快捷键 Ctrl/Cmd + `。
  • 下载 ngdbc 超时：BAS 能访问公网；若慢，换 Maven Central 或让 Maven 在 pom 里自动拉（模式二/三）。
  • 工作区被重置：BAS Dev Space 会随 trial 生命周期回收，重要代码建议提交到 git（BAS 内置 Source Control 支持连 GitHub）。
