第 B4 章：手顺2 HANA SQL 建表与数据

在 Database Explorer 里执行 SQL：建 schema → 建 3 张表 → 灌入 10 本书 → 联表验证

HANA Cloud 实例就绪后，我们开始用 HANA SQL 构建 Bookshop 数据库。与前面 CAP 路线（CDS 自动建表）不同，这里是手写 DDL：一个 schema、三张表（含外键）、一批种子数据。数据与站点 CAP 路线完全一致——这样 B6–B8 三种 Java 模式连上来，读到的还是那 10 本书。

HANA SQL CREATE SCHEMA CREATE COLUMN TABLE 外键约束 种子数据

B4.1 打开 SQL Console

B4.2 建 schema

schema（架构）是 HANA 里组织对象的第一层容器。DBADMIN 默认有 CREATE SCHEMA 权限，直接建：

-- 01 建 schema（BOOKSHOP）
CREATE SCHEMA BOOKSHOP;

成功后，左侧 Catalog 下会出现 BOOKSHOP 这个 schema。

B4.3 建三张表（含外键）

Bookshop 数据模型是「书 → 作者 / 分类」：BOOKS 通过 AUTHOR_ID 引用 AUTHORS、GENRE_ID 引用 GENRES。HANA 用 CREATE COLUMN TABLE（列式存储，分析/OLTP 都推荐）建表：

-- 02 建表：GENRES（分类） / AUTHORS（作者） / BOOKS（书，含外键）
-- 顺序：先父表，再子表（BOOKS 引用前两张表）
CREATE COLUMN TABLE BOOKSHOP.GENRES (
  ID    INT PRIMARY KEY,
  NAME  NVARCHAR(64)  NOT NULL,
  DESCR NVARCHAR(512)
);

CREATE COLUMN TABLE BOOKSHOP.AUTHORS (
  ID             INT PRIMARY KEY,
  NAME           NVARCHAR(128)  NOT NULL,
  DATE_OF_BIRTH  DATE,
  PLACE_OF_BIRTH NVARCHAR(128)
);

CREATE COLUMN TABLE BOOKSHOP.BOOKS (
  ID        INT PRIMARY KEY,
  TITLE     NVARCHAR(256) NOT NULL,
  DESCR     NVARCHAR(1024),
  AUTHOR_ID INT NOT NULL,
  GENRE_ID  INT NOT NULL,
  STOCK     INT DEFAULT 0,
  PRICE     DECIMAL(9,2),
  CURRENCY  NVARCHAR(3),
  CONSTRAINT FK_BOOKS_AUTHOR FOREIGN KEY (AUTHOR_ID) REFERENCES BOOKSHOP.AUTHORS (ID),
  CONSTRAINT FK_BOOKS_GENRE  FOREIGN KEY (GENRE_ID)  REFERENCES BOOKSHOP.GENRES  (ID)
);
💡 三个类型要点
  • NVARCHAR：HANA 的 Unicode 变长字符串，中文「哥特小说代表作」这类描述用它。
  • INT PRIMARY KEY：主键即内联的主键约束；外键用独立的 CONSTRAINT ... FOREIGN KEY ... REFERENCES 声明，保证 BOOKS.AUTHOR_ID 必须存在于 AUTHORS。
  • DECIMAL(9,2)：金额用定点数，避免浮点误差（价格 11.11 / 33.00 这类）。

B4.5 验证

最后跑一段联表查询，把「书 + 作者名 + 分类名」取出来，并用计数核对总数。这段 SQL 与后面三个 Java 程序用的完全一样：

-- 04 验证：联表查询（Java 三种模式用同一条）
SELECT b.ID, b.TITLE,
       a.NAME AS AUTHOR, g.NAME AS GENRE,
       b.STOCK, b.PRICE, b.CURRENCY
FROM BOOKSHOP.BOOKS b
  JOIN BOOKSHOP.AUTHORS a ON a.ID = b.AUTHOR_ID
  JOIN BOOKSHOP.GENRES  g ON g.ID = b.GENRE_ID
ORDER BY b.ID;

-- 计数核对：期望 Books 10 / Authors 4 / Genres 5
SELECT 'BOOKS' AS TBL, COUNT(*) AS CNT FROM BOOKSHOP.BOOKS
UNION ALL
SELECT 'AUTHORS', COUNT(*) FROM BOOKSHOP.AUTHORS
UNION ALL
SELECT 'GENRES',  COUNT(*) FROM BOOKSHOP.GENRES;

B4.6 操作手顺

  1. 打开 SQL Console

    Database Explorer → 选中 bookshop-hana 实例 → SQL Console（见图 B4-1）。

  2. 执行 01 建 schema

    粘贴 CREATE SCHEMA BOOKSHOP; 并运行，左侧 Catalog 出现 BOOKSHOP。

  3. 执行 02 建三张表

    先 GENRES / AUTHORS，再 BOOKS（含两个外键约束），全部运行成功（见B4.3）。

  4. 执行 03 灌种子数据

    三段 INSERT（分类 / 作者 / 书）分别运行，每段都提示成功（见B4.4）。

  5. 执行 04 验证

    联表查询应返回 10 行；计数查询返回 10 / 4 / 5（见B4.5）。数据就绪，可以进 B5 章搭开发环境了。

⚠️ 常见问题
  • 重复执行报「table already exists」：02 建表段不能跑两次。重来用 DROP SCHEMA BOOKSHOP CASCADE; 清空后从 01 重跑。
  • 报 insufficient privilege：你用的是非 DBADMIN 用户。两种办法：GRANT CREATE SCHEMA TO <user>；或跳过 schema，直接用该用户默认 schema 建表（此时 SQL 去掉 BOOKSHOP. 前缀，Java 里的 SQL 同样去掉）。
  • 外键插入失败：必须先灌 GENRES/AUTHORS 再灌 BOOKS，否则 AUTHOR_ID 引用不到会报错。
  • 中文乱码：SQL Console 默认 UTF-8，一般不会乱码；若乱码，检查浏览器与文件编码统一为 UTF-8。
