第 B2 章：环境准备（BTP 账号）

注册 SAP 账号 → 进入 Cockpit → 建子账号 → 启用 Cloud Foundry —— 拿到「云上动手」的入场券

本轨所有云端操作都发生在 SAP BTP Cockpit（浏览器管理台）里。第一步是有一个账号：个人学习用 SAP Trial（免费试用） 就够；企业开发用 Enterprise 账号。本章把从注册到「子账号 + Cloud Foundry 空间」就绪的链路走通。

SAP BTP Cockpit Global Account 子账号 Cloud Foundry org / space cf CLI（可选）

B2.1 注册 SAP 账号

前往 SAP BTP 官网 或用搜索引擎搜「SAP BTP trial」，找到 Start a free trial / Free Tier 入口注册。注册时需要一个工作邮箱，按邮件激活。之后进入 Cockpit：

  • Trial 账号：免费，随开随用；会自动送你一个 trial Global Account 与子账号（地区可选，如 US East / Japan）。缺点：HANA Cloud 实例每日自动停止（B3 章会提醒）。
  • Enterprise 账号：公司付费账号，功能与容量不受 trial 限制。操作界面与 trial 一致，本课程手顺通用。
📌 地区选择 注册时选的地区决定你的数据中心与 HANA Cloud 主机后缀（如 trial-us10）。选离你近的即可；本课程示例主机 xxxx.hana.trial-us10.hanacloud.ondemand.com 就是「us10」地区——你的会不同，B3 章会教你从实例里复制真正的地址。

B2.2 进入 Cockpit：Global Account 与子账号

登录后先看 Global Account（全局账户，公司/个人的顶层容器），里面可以建多个 子账号（Subaccount）——每个子账号是独立的资源配置单元。Trial 会自动建好一个子账号，你通常直接在里面干活：

B2.4（可选）cf CLI 登录

云数据库的创建走界面（B3 章）；若之后要用 cf 命令行部署，可顺手装 Cloud Foundry CLI 并登录。macOS：brew install cloudfoundry/tap/cf-cli@8。登录命令里的 API endpoint 可在子账号 Overview 的 Cloud Foundry Environment 区块查到（形如 api.cf.us10.hana.ondemand.com）：

B2.5 操作手顺

  1. 注册 SAP 账号

    在 SAP BTP 官网点 Start a free trial，用工作邮箱注册并激活。有企业账号则直接用企业账号。

  2. 进入 Cockpit，确认子账号

    登录后进入 Global Account → Subaccounts，确认存在 trial 子账号（Enterprise 账号则手动创建一个子账号，区域任选）。点名称进入子账号（见图 B2-1）。

  3. 启用 Cloud Foundry

    子账号 Overview → Cloud Foundry Environment → Create，Organization 填 trial、Space 填 dev，点 Enable（见图 B2-2）。

  4. 记下子账号关键信息

    记下 子账号名称 与 区域（Region）（如 us10）。B3 章在 Service Marketplace 创建 HANA Cloud 时要用。

  5. 整体验证

    子账号 Overview 显示 Cloud Foundry Environment: CREATED，且能看到 org / space 即可。B3 章将在这里创建 HANA Cloud 实例。

⚠️ 常见问题
  • 找不到 trial 入口：SAP 官网改版频繁，直接搜「SAP BTP trial sign up」，或从 help.sap.com 的 Getting Started 页面进入。
  • 地区与免费额度：trial 的 HANA Cloud 只有特定地区有免费额（如 us10）；若所选地区不可创建，换一个地区重开 trial。
  • 子账号里没有 Cloud Foundry：Enterprise 账号默认不自动建 CF，需在子账号 → Overview → Cloud Foundry 手动 Create，并绑定一个 quota。

答案与解析（🟢 基础巩固（1–7））
题号答案解析
1ATrial 免费、几步注册即可；企业开发才需要 Enterprise 账号。
2ACockpit 是云端控制台：管理账号层级、服务、成员等。
3AGlobal Account 是顶层合同单位，子账号是其下的资源/环境单元。
4A每个子账号下可建 org，org 下建 space；配额与应用都挂在 space。
5ABTP 服务以实例/订阅形式挂在子账号，运行时空间引用之。
6Acf 是 CF 官方 CLI：登录、部署、查看应用状态（本轨可选安装）。
7ATrial 开箱即给子账号与 CF 环境，可直接进入后续手顺。
