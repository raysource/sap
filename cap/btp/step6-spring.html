第 B8 章：手顺6 模式三 Spring Boot

最接近真实生产的模式：start.spring.io 生成 Web 工程 → JdbcTemplate 读库 → REST 接口 /api/books → curl 验证

模式三是把程序变成一个真正的 Web 服务：用 Spring Boot 起一个 HTTP 服务器，暴露 GET /api/books，浏览器或 curl 一调就返回 HANA Cloud 里那 10 本书的 JSON。JDBC 不再手写样板，交给 Spring 的 JdbcTemplate。这也是 CAP Java（J1–J6）的运行底座。

start.spring.io Spring Boot Web JdbcTemplate @RestController curl JSON

B8.1 用 start.spring.io 生成工程

Spring 官方脚手架 start.spring.io 会生成一个可直接跑的工程。用 curl 拉 zip（依赖 web + jdbc，Java 17），解压：

cd projects

curl -G https://start.spring.io/starter.zip \
  -d dependencies=web,jdbc -d type=maven-project \
  -d language=java -d javaVersion=17 \
  -d groupId=com.acme -d artifactId=bookshop-spring \
  -o bookshop-spring.zip

unzip bookshop-spring.zip
cd bookshop-spring
📌 没有 curl？也可以开浏览器 打开 https://start.spring.io，左侧选 Maven · Java · 17，Dependencies 搜 Spring Web 与 Spring Data JDBC 添加，Project 填 com.acme / bookshop-spring，点 Generate 下载 zip，解压到 projects。效果与 curl 一致。

B8.2 给 pom.xml 加 ngdbc 依赖

生成的 pom.xml 已含 spring-boot-starter-web 与 spring-boot-starter-jdbc（Spring Boot 版本由 start.spring.io 决定，无需改）。只需加入 ngdbc 依赖块：

<!-- 加在 pom.xml 的 <dependencies> 里 -->
<dependency>
  <groupId>com.sap.cloud.db.jdbc</groupId>
  <artifactId>ngdbc</artifactId>
  <version>2.28.8</version>
</dependency>

（版本号同样以 Maven Central 为准。）

B8.3 配置 application.properties

Spring Boot 用 src/main/resources/application.properties 配置数据源。把 spring.datasource.* 指到你的 HANA Cloud（注意 JDBC URL 里的 & 在 properties 中也要原样保留，主机与口令换成 B3.3 记的）：

# 连接 HANA Cloud 的 BOOKSHOP 库
spring.datasource.url=jdbc:sap://xxxx.hana.trial-us10.hanacloud.ondemand.com:443?encrypt=true&validateCertificate=true
spring.datasource.username=DBADMIN
spring.datasource.password=你的数据库口令

server.port=8080

Spring Boot 会自动把 spring.datasource 前缀的配置接成 DataSource，注入给 JdbcTemplate——这行配置就是 B7 里 DriverManager.getConnection(URL, USER, PASSWORD) 的「声明式」版本。

B8.4 写应用代码（入口 + DTO + Controller）

三个文件：入口 Application.java、数据类 Book.java（record，自动序列化为 JSON）、接口 BookController.java（JdbcTemplate 查库）。都放在 src/main/java/com/acme/bookshop/：

package com.acme.bookshop;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

/** 模式三 · Spring Boot 应用入口 */
@SpringBootApplication
public class Application {

    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
package com.acme.bookshop;

/**
 * 图书 DTO：对应 BOOKSHOP.BOOKS 联表查询结果，直接序列化为 JSON
 * （Spring Boot 对 record 自动做 JSON 序列化，无需 getter）
 */
public record Book(
        int id,
        String title,
        String author,
        String genre,
        int stock,
        double price,
        String currency) {
}
package com.acme.bookshop;

import java.util.List;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

/**
 * GET /api/books → 用 JdbcTemplate 读 HANA Cloud 的 BOOKSHOP.BOOKS，
 * 联表取出作者名 / 分类名，返回 JSON 数组（10 个对象）。
 */
@RestController
public class BookController {

    private final JdbcTemplate jdbc;

    public BookController(JdbcTemplate jdbc) {
        this.jdbc = jdbc;
    }

    @GetMapping("/api/books")
    public List<Book> books() {
        String sql =
            "SELECT b.ID, b.TITLE, a.NAME AS AUTHOR, g.NAME AS GENRE, " +
            "       b.STOCK, b.PRICE, b.CURRENCY " +
            "  FROM BOOKSHOP.BOOKS b " +
            "  JOIN BOOKSHOP.AUTHORS a ON a.ID = b.AUTHOR_ID " +
            "  JOIN BOOKSHOP.GENRES  g ON g.ID = b.GENRE_ID " +
            " ORDER BY b.ID";
        return jdbc.query(sql, (rs, rowNum) -> new Book(
                rs.getInt("ID"), rs.getString("TITLE"), rs.getString("AUTHOR"),
                rs.getString("GENRE"), rs.getInt("STOCK"),
                rs.getDouble("PRICE"), rs.getString("CURRENCY")));
    }
}

B8.5 运行与测试

一条命令起服务；另开一个终端用 curl 调接口。Spring Boot 内嵌 Tomcat，监听 8080（properties 里设的）：

mvn spring-boot:run
BAS 终端 — mvn spring-boot:run
$ mvn spring-boot:run

[INFO] ...

B8.6 操作手顺

  1. 生成工程

    执行 B8.1 的 curl（或浏览器 start.spring.io）生成 bookshop-spring 并解压、进入目录。

  2. 加 ngdbc 依赖

    在生成 pom.xml 的 <dependencies> 里加 ngdbc 依赖块（见B8.2）。

  3. 配置数据源

    覆盖 src/main/resources/application.properties，填主机与 DBADMIN 口令（见B8.3）。

  4. 写三个 Java 文件

    覆盖/新建 Application.java、Book.java、BookController.java（见B8.4）。

  5. 启动并测试

    mvn spring-boot:run 起服务，另开终端 curl http://localhost:8080/api/books，看到 10 本书 JSON 即成功（见图 B8-1）。

  6. 三种模式横向对照

    回到 B6/B7 的输出，三者读的是同一张 BOOKSHOP.BOOKS、同一段 SQL，数据必然一致——只是「构建方式」从手编、到 Maven、再到 Spring 框架的差别。

⚠️ 常见问题
  • 端口被占：改 server.port=8081 再试；或 lsof -i :8080 看占用进程。
  • Connection refused：确认 HANA Cloud 实例 RUNNING（trial 每日自动停，需手动 Start）。
  • Properties 里密码含特殊字符：#、! 等在 properties 里要转义或用引号；更稳妥是放进环境变量（进阶做法）。
  • start.spring.io 返回的 boot 版本要求更高 JDK：若编译报「invalid source release」或「requires JDK 21」，在 start.spring.io 页面把 Java 版本调低一档（如 17 → 21 匹配新 JDK，或改用 Boot 2.7 系 + Java 17）。
  • curl 返回 500：看服务端日志堆栈——通常是连接参数或 SQL 前缀（非默认 schema 用户要去掉 BOOKSHOP.）。
