第 B3 章：手顺1 创建 HANA Cloud 实例

Service Marketplace 创建实例 → 等 RUNNING → 打开 Database Explorer → 记下连接信息

本章创建本轨的「数据库主角」：一个 HANA Cloud 实例。创建要等十几分钟到半小时（trial 也要等），期间可以先做 B5 章的 BAS 部分。创建完成后，拿到三样关键信息：SQL End Point 主机、端口、DBADMIN 口令——后面所有 Java 代码都靠它们连库。

⏳ 等待期间做什么 实例创建要等十几分钟。这段时间可以先去 B5 章 创建 BAS Dev Space、搭好开发环境；也可以先看 B4 章把 SQL 读懂，等实例就绪直接跑。

B3.3 记录连接信息（SQL End Point）

回到 HANA Cloud（Central）→ 点实例名进入详情，找到 Copy SQL End Point 按钮——它就是 Java 程序连库用的主机与端口：

实例详情 bookshop-hana
SQL End Point
bcb7a5f2-xxxx.hana.trial-us10.hanacloud.ondemand.com:443
↑ 点 Copy SQL End Point 复制。这就是 JDBC URL 里的主机 + 端口（443）。
管理员用户：DBADMIN（创建实例时设的口令就是它的密码）
图 B3-4 实例详情页：Copy SQL End Point 给的是 主机:端口（端口固定 443）。把它和 DBADMIN 口令记到你的笔记里——B6–B8 章的三个 Java 程序都要用
📌 本轨连接信息速记表 后面每个 Java 程序都会出现这几个占位符，统一替换成你的真实值：主机 = SQL End Point 的前半段、端口 = 443、用户名 = DBADMIN、口令 = 创建实例时设置的密码。JDBC URL 统一格式：jdbc:sap://<主机>:443?encrypt=true&validateCertificate=true。

B3.4 操作手顺

  1. 进入 Service Marketplace

    子账号 → Service Marketplace，搜 HANA Cloud，点卡片 Create Instance。

  2. 填写向导并创建

    实例名 bookshop-hana，Plan hana（trial 免费），设置并记录 DBADMIN 口令，点 Create（见图 B3-1）。

  3. 等待 RUNNING

    在 SAP HANA Cloud（Central） 观察状态 CREATING → RUNNING，约 10–30 分钟（见图 B3-2）。期间可先做 B5 章。

  4. 打开 Database Explorer 并连通

    实例行 ⋮ → Open SAP HANA Database Explorer，确认左侧出现 bookshop-hana 且已连接（见图 B3-3）。

  5. 记录连接信息

    实例详情 → Copy SQL End Point，记录主机与端口 443；确认 DBADMIN 口令（见图 B3-4）。B4 章开始用。

⚠️ 常见问题
  • 创建很慢 / 报错：trial 地区可能没有免费额度，换 us10 / jp10 等地区重开；Enterprise 需先给子账号分配 HANA Cloud quota。
  • 实例每日自动停止：trial 版 HANA Cloud 每天会自动 STOPPED，连不上时回实例详情点 Start 手动重启（约几分钟）。
  • Database Explorer 打不开：先确认实例 RUNNING；打不开时改用 B5 章 BAS 里装的 Database Explorer 扩展连接同一实例。
  • 口令忘了：无法找回，只能删实例重建（建表数据也随之丢失）。务必记在密码管理器里。
