第 B6 章：手顺4 模式一 目录式构建

不依赖任何构建工具：两个 .java + 一个 ngdbc.jar，用 javac / java 直连 HANA Cloud 读出 10 本书

这是最简单的模式，也是理解 JDBC 本质最好的方式：不用 Maven、不用 Spring，只有两个 Java 文件（一个 DTO、一个主程序）和 ngdbc 驱动 jar。你手写 JDBC 连接、手写查询、手写格式化输出——把所有「魔法」都摊开在面前。

javac / java JDBC classpath ngdbc.jar UTF-8 编译

B6.1 目录结构

在 BAS 终端里建目录（B5.4 已建好 lib/），把源码放在标准包路径下：

bookshop-dir — 目录树
▾📁 bookshop-dir （工作目录）
▾📁 lib
📄 ngdbc.jar ← B5.4 下载的驱动
▾📁 src/com/acme/bookshop
📄 Book.java ← 书的 DTO
📄 BookshopApp.java ← 主程序（入口）
▾📁 out ← javac 编译输出（自动生成）
图 B6-1 目录式工程结构：源码在 src/com/acme/bookshop/，驱动在 lib/，编译结果进 out/

B6.2 第一个文件：Book.java（DTO）

一个普通 POJO，字段对应 B4.5 联表查询的列。它有两个方法：line() 输出一行格式化文本、header() 输出表头：

package com.acme.bookshop;

/**
 * 一本书的简单 DTO：字段对应 BOOKSHOP.BOOKS 联表查询结果
 * （ID、TITLE、作者名、分类名、STOCK、PRICE、CURRENCY）
 */
public class Book {
    public int id;
    public String title;
    public String author;
    public String genre;
    public int stock;
    public double price;
    public String currency;

    public Book(int id, String title, String author, String genre,
                int stock, double price, String currency) {
        this.id = id;
        this.title = title;
        this.author = author;
        this.genre = genre;
        this.stock = stock;
        this.price = price;
        this.currency = currency;
    }

    /** 一行格式化输出（对齐示例输出） */
    public String line() {
        return String.format("%-2d  %-22s  %-18s  %-16s  %4d  %8.2f  %s",
                id, title, author, genre, stock, price, currency);
    }

    /** 表头 */
    public static String header() {
        return String.format("%-2s  %-22s  %-18s  %-16s  %4s  %8s  %s",
                "ID", "TITLE", "AUTHOR", "GENRE", "STOCK", "PRICE", "CURR");
    }
}

B6.3 第二个文件：BookshopApp.java（主程序）

JDBC 三板斧：DriverManager.getConnection(URL, USER, PASSWORD) → prepareStatement(SQL) → 遍历 ResultSet。把三处 TODO 占位符换成 B3.3 记下的真实值即可：

package com.acme.bookshop;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.util.ArrayList;
import java.util.List;

/**
 * 模式一 · 目录式构建（纯 javac / java）
 * 直接 JDBC 连接 HANA Cloud 的 BOOKSHOP 库，联表读取 Books 打印。
 */
public class BookshopApp {

    // TODO: 换成你 HANA Cloud 实例的 SQL End Point 主机（B3 章「Copy SQL End Point」）
    static final String HOST = "xxxx.hana.trial-us10.hanacloud.ondemand.com";
    static final String URL =
        "jdbc:sap://" + HOST + ":443?encrypt=true&validateCertificate=true";
    static final String USER = "DBADMIN";
    static final String PASSWORD = "你的数据库口令";   // TODO: 替换为 DBADMIN 口令

    static final String SQL =
        "SELECT b.ID, b.TITLE, a.NAME AS AUTHOR, g.NAME AS GENRE, " +
        "       b.STOCK, b.PRICE, b.CURRENCY " +
        "  FROM BOOKSHOP.BOOKS b " +
        "  JOIN BOOKSHOP.AUTHORS a ON a.ID = b.AUTHOR_ID " +
        "  JOIN BOOKSHOP.GENRES  g ON g.ID = b.GENRE_ID " +
        " ORDER BY b.ID";

    public static void main(String[] args) throws Exception {
        Class.forName("com.sap.db.jdbc.Driver");
        List<Book> books = new ArrayList<>();
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement ps = conn.prepareStatement(SQL);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                books.add(new Book(
                    rs.getInt("ID"),
                    rs.getString("TITLE"),
                    rs.getString("AUTHOR"),
                    rs.getString("GENRE"),
                    rs.getInt("STOCK"),
                    rs.getDouble("PRICE"),
                    rs.getString("CURRENCY")));
            }
        }
        System.out.println("共读取 " + books.size() + " 本书（BOOKSHOP.BOOKS）");
        System.out.println(Book.header());
        for (Book b : books) System.out.println(b.line());
    }
}
💡 为什么 URL 是 encrypt=true&validateCertificate=true HANA Cloud 是公网数据库，只允许 TLS 加密连接并校验证书。这两个参数就对应「加密」与「校验证书」，请保持 true——这不是可选项。主机名用你实例的 SQL End Point，端口固定 443。

B6.4 编译与运行

在 BAS 终端进入 bookshop-dir，用 javac 把两个文件编译进 out/（-encoding UTF-8 保证中文正常；-cp 指明驱动在 lib/），再用 java 运行（classpath 用 out:lib/ngdbc.jar）：

cd bookshop-dir

# 1) 编译（classpath 只需 ngdbc.jar；Linux/macOS 分隔符是冒号 :）
javac -encoding UTF-8 -cp lib/ngdbc.jar -d out \
  src/com/acme/bookshop/Book.java \
  src/com/acme/bookshop/BookshopApp.java

# 2) 运行
java -cp "out:lib/ngdbc.jar" com.acme.bookshop.BookshopApp

B6.5 操作手顺

  1. 建目录结构

    在 BAS 工作区建 bookshop-dir/src/com/acme/bookshop/，确认 lib/ngdbc.jar 已就位（B5.4）。

  2. 写 Book.java

    在 src/com/acme/bookshop/ 新建 Book.java，粘贴 B6.2 代码。

  3. 写 BookshopApp.java

    同目录新建 BookshopApp.java，粘贴 B6.3 代码，把 HOST 与 PASSWORD 换成 B3.3 记录的真实值。

  4. 编译

    执行 B6.4 的 javac 命令。无输出即成功；报错时看提示（常见：路径、编码）。

  5. 运行并核对

    执行 java 命令，看到「共读取 10 本书」+ 10 行即成功（见图 B6-2）。与 B4.5 SQL 结果比对，数据应一致。

⚠️ 常见问题
  • ClassNotFoundException: com.sap.db.jdbc.Driver：classpath 没包含 lib/ngdbc.jar（编译或运行时漏了 -cp）。
  • 连接超时 / UnknownHost：主机名拼错，或实例停了（trial 每日自动停，回 Cockpit Start）。
  • Authentication failed：DBADMIN 口令错；口令含特殊字符时注意终端转义。
  • 编码乱码：编译时务必带 -encoding UTF-8，且源码文件存为 UTF-8。
  • 找不到主类：运行时的包名 com.acme.bookshop.BookshopApp 要和你 package 声明一致。
